Proof before output

An answer is only one valid outcome.

When approved knowledge supports a response, Bast keeps the source route visible. When nothing supports it, the system refuses before the model guesses.

Answer

Supported questions move forward.

Trace

The route stays inspectable.

Source, ontology, version, and routing remain tied to the delivered response.

Refuse

A clean no beats a confident guess.

If nothing supports the answer, Bast stops instead of filling the gap with fluency.
